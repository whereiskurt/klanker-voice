<objective>
Land the pause mechanism itself: the `paused` boolean in `site.hcl`, the `ecs_services`
for-expression that turns it into both required overrides, and the Go rewriter that flips it
without touching anything else in the file.

Purpose: D-16 is the hazard that makes a naive pause fail while reporting success. Application
Auto Scaling enforces `min_capacity = 1`, so `desired_count = 0` alone bounces back, and
`min_capacity = 0` alone changes nothing. Both overrides, or the pause is broken. And because
`kv pause` commits this file to `main` unattended, the rewriter has to be provably surgical —
hence the table tests on idempotence, comment preservation, already-paused, and malformed input.

Output: the edited `infra/terraform/live/site/site.hcl`, `kv/internal/app/cmd/lifecycle_pauseflag.go`,
its table tests, and four HCL fixtures under `kv/internal/app/cmd/testdata/site-hcl/`.
</objective>
